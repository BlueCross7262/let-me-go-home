## 2. 목적 및 범위

`src/text.js` 의 공백 정리 함수 `trimAll` 을 `normalizeSpace` 로 바꾸고 안쪽 연속 공백 축약을 더한다.
같은 파일에 `slugify(value)` 를 더한다.
`test/` 를 새 이름과 slugify 에 맞춘다.

### In-scope

- `src/text.js` 의 `trimAll` 을 `normalizeSpace` 로 이름 변경하고 동작을 앞뒤 공백 제거와 안쪽 연속 공백 축약으로 바꾼다.
- `trimAll` 을 `src/text.js` 에서 지운다.
- `src/text.js` 에 `slugify(value)` 를 더한다.
- `test/` 의 테스트를 `normalizeSpace` 로 바꾸고 slugify 테스트를 더한다.

### Non-Goal

- NG-01 — 기능 B(`src/date.js`, `formatDate`)를 이 Phase 에서 만들지 않는다.
- NG-02 — `trimAll` 호환 alias 를 두지 않는다.
- NG-03 — `src/config.js` 를 바꾸지 않는다.

## 3. 기능 요구사항

- FR-01 — `src/text.js` 가 `normalizeSpace(value)` 를 export 하고, 이 함수는 앞뒤 공백을 지우고 안쪽 연속 공백을 공백 하나로 줄인다.
- FR-02 — `normalizeSpace` 가 공백으로 보는 문자는 정규식 `\s` 가 매치하는 모든 공백 문자다.
- FR-03 — `src/text.js` 가 `trimAll` 을 export 하지 않는다.
- FR-04 — `src/` 와 `test/` 의 `trimAll` 참조를 `normalizeSpace` 로 바꾼다.
- FR-05 — `src/text.js` 가 `slugify(value)` 를 export 하고, 이 함수는 영문 대문자를 소문자로 바꾸고 공백을 하이픈으로 바꾼다.
- FR-06 — `slugify` 는 결과 앞뒤의 하이픈을 지운다.
- FR-07 — `slugify` 는 연속 하이픈을 하이픈 하나로 합친다.
- FR-08 — `slugify` 는 영문·숫자·하이픈이 아닌 문자를 지운다.
- FR-09 — `slugify` 가 하이픈으로 바꾸는 공백은 정규식 `\s` 가 매치하는 모든 공백 문자다.
- FR-10 — `slugify` 는 입력 자체의 앞뒤 하이픈도 지운다.
- FR-11 (NG-01) — 이 Phase 의 변경은 `src/date.js` 를 만들지 않는다.
- FR-12 (NG-02) — `src/text.js` 는 `trimAll` 이라는 이름의 선언이나 re-export 를 두지 않는다.
- FR-13 (NG-03) — 이 Phase 의 변경은 `src/config.js` 를 바꾸지 않는다.
