# Contributing

Read `CLAUDE.md` first. It holds the repository layout, the invariants a change
must not break, and the build and test commands. This file only covers what it
does not.

## Before you open a change

- `npx tsc --noEmit` passes.
- `npm run build` exits 0. If you added a module, its compiled output under
  `dist/` belongs in the same commit — those directories are tracked on purpose.
- `npm run test:run` produces the **same set of failing test names** as it did
  before your change. The suite is not clean on Windows and has not been since
  before the fork; comparing counts is not enough, compare names.

## What will be rejected

- Anything that registers a `PreToolUse` or `PostToolUse` hook, or adds a
  per-tool matcher to an existing event. Removing those is why this fork exists.
- A namespace string written as a literal in production code. It belongs in
  `src/constants/namespace.ts`, which every consumer imports.
- A hand edit to `scripts/lib/namespace.mjs`. It is generated by
  `scripts/build-namespace.mjs`.
- An `import` from `dist/` at module load in a `scripts/**.mjs` file. Those
  scripts run when the build output is absent.

## Scope

The plugin ships Ralph and Deep Interview. A feature that neither of them
reaches is out of scope regardless of its merit — the whole point of the fork is
a small, cheap surface.

## Commits

Describe what changed and why it is correct. When a change deletes something,
say what proved it was unreachable. When it touches the Stop hook or the state
tools, say how you verified the behaviour — those two decide whether a session
can end.
