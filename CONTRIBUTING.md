# Contributing

Read `CLAUDE.md` first. It holds the repository layout, the invariants a change
must not break, and the build and test commands. This file only covers what it
does not.

## Before you open a change

- `npx tsc --noEmit` passes.
- `npm run build` exits 0. If you added a module, its compiled output under
  `dist/` belongs in the same commit — those directories are tracked on purpose.
- `npm run test:run` produces the **same set of failing test names** as it did
  before your change. The suite is not clean on Windows and has not been since
  before the fork; comparing counts is not enough, compare names.

## What will be rejected

- Anything that registers a `PostToolUse` hook, adds a `PreToolUse` entry
  beside the `Agent|Task` model gate, widens that matcher, or adds a per-tool
  matcher to another event. Removing those is why this fork exists.
- A namespace string written as a literal in production code. It belongs in
  `src/constants/namespace.ts`, which every consumer imports.
- A hand edit to `scripts/lib/namespace.mjs`. It is generated by
  `scripts/build-namespace.mjs`.
- An `import` from `dist/` at module load in a `scripts/**.mjs` or `hooks/*.mjs` file. Those
  scripts run when the build output is absent.

## Choosing a stop layer

A skill that must hold the session open through the `Stop` hook writes a
control record in one stop layer. It does not write its own stop state file.

The layers are ordered. When more than one is live, the highest-numbered layer
(the innermost) decides the turn and the others only get `last_checked_at`
refreshed. No layer belongs to a fixed owner:

- `stop-layer.mjs on --layer auto` takes the first free layer, from `first`.
- Ralph (`startLoop`) takes the first free layer above the highest live holder,
  so it stays inside a holder that is already running. When no free layer sits
  above that holder, it takes the lowest free layer and the bootstrap summary
  reports `layer_inner_shadowed`.
- A skill that starts later on a higher layer therefore decides over one that
  started earlier on a lower layer. An explicit `--layer` that a live owner
  holds is refused.

Write a layer through `stop-layer.mjs`, and clear it when the work ends. A layer
that another owner holds refuses the write and names the free layers. Profiles
live in `scripts/lib/stop-profiles.json`; `src/lib/stop-control.ts` carries a
copy and a test keeps the two equal.

The `stop-layer` script (`scripts/stop-layer.mjs`) is the write path a skill
calls: `on` (with `--input-file` for a profile, messages and fields), `refresh`,
`off`, `clear` and `status`. A domain write never touches a control record:
`state_write(mode="ralph")` changes the Ralph state file only, and the hook
counters and the continue text stay in the layer record.

## Scope

The plugin ships Ralph and Deep Interview. A feature that neither of them
reaches is out of scope regardless of its merit — the whole point of the fork is
a small, cheap surface.

## Commits

Describe what changed and why it is correct. When a change deletes something,
say what proved it was unreachable. When it touches the Stop hook or the state
tools, say how you verified the behaviour — those two decide whether a session
can end.
